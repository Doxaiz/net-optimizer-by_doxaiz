# Net Optimizer by Doxaiz

Android-приложение для диагностики мобильной сети 4G/5G. Без регистрации, подписки и собственного сервера. Для измерений используются сторонние сетевые узлы. Android 12+ (API 31), target SDK 34.

Приложение показывает доступные данные сотовой сети, выполняет сетевые измерения и сохраняет ручные сессии локально. Некоторые функции из прежних описаний пока не реализованы: VPN-фильтрация, фоновый автопилот и принудительное переключение сети. Актуальные ограничения и результаты аудита — в [AUDIT.md](AUDIT.md). Работу на Infinix Hot 50 необходимо проверить на устройстве.

## Подпись release-сборки

Ключ подписи и пароли не должны находиться в исходниках. В настройках репозитория GitHub Actions → Secrets and variables → Actions необходимо добавить следующие **repository secrets**:

- `ANDROID_KEYSTORE_BASE64` — содержимое файла хранилища ключа в Base64 без переносов строк.
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища.
- `ANDROID_KEY_ALIAS` — alias ключа.
- `ANDROID_KEY_PASSWORD` — пароль ключа.

Секреты нельзя передавать в чат, добавлять в Git или публиковать в артефактах. CI создаёт временный файл на runner и удаляет его после сборки. При отсутствии секретов release-сборка завершается ошибкой, а не выдаёт неподписанный APK. Unit-тесты и lint не требуют ключа. На локальной машине для `gradle assembleRelease` задайте переменные окружения `ANDROID_KEYSTORE_PATH` (абсолютный путь к файлу ключа), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`. Для сборки необходимы JDK 17, Gradle 8.7 и Android SDK 34.

**Старый ключ был опубликован вместе с паролем и скомпрометирован.** Удаление из текущей ветки не удаляет его из истории, других веток, клонов и ранее опубликованных APK. Безопасное решение — новый ключ, хранящийся вне репозитория. APK с новым ключом обычно нельзя установить поверх старой версии: перед удалением приложения сохраните нужные данные. Самостоятельная очистка истории и переписывание чужих веток здесь не проводились.

## Получение APK

После настройки секретов workflow **Build APK** запускает тесты, собирает подписанный release и сохраняет его как артефакт GitHub Actions. Он не публикует релиз автоматически. Подпись сама по себе не гарантирует отсутствие предупреждений Play Защиты.
