# Net Optimizer by Doxaiz

## ▶️ Быстрый старт: сборка через GitHub Actions

1. Создайте репозиторий на GitHub (например `net-optimizer-doxaiz`).
2. Залейте содержимое этой папки в корень репозитория.
3. Откройте вкладку **Actions** → слева **Build APK** → **Run workflow** → **Run workflow**.
4. Через 3–6 минут в завершившемся запуске появится артефакт
   **NetOptimizer-by-Doxaiz-release** — внутри `app-release.apk` (подписан, ставится без Play Защиты).

Сборка запускается автоматически при любом push в `main`/`master`.

### Подпись

В корне лежит тестовый ключ `doxaiz-release.jks`:

| Параметр | Значение |
|---|---|
| alias | `doxaiz` |
| пароль хранилища | `doxaiz2026` |
| пароль ключа | `doxaiz2026` |
| Владелец | `CN=Doxaiz, O=Doxaiz, C=RU` |

Если ключ удалить, сборка не сломается — APK соберётся без подписи
(но такой файл телефон не установит). Перед реальным релизом
сгенерируйте свой ключ и обновите `app/build.gradle.kts`.

### Сборка локально

```
gradle assembleRelease          # подписанный релиз
gradle assembleDebug            # отладочный (Play Защита блокирует)
```

Нужны JDK 17 и Android SDK 34. Файл `local.properties` с путём к SDK
создаётся автоматически Android Studio и в репозиторий не входит.

# Net Optimizer by Doxaiz

Честный оптимизатор мобильной связи (4G/5G), скорости интернета и пинга для Android.
100% бесплатно, без подписок, без регистрации, без рекламы. Open Source.

## Что умеет
- Живой мониторинг сигнала 4G/5G: RSRP, RSRQ, SINR, Band, агрегация LTE-A, 5G NR
- Кнопка «⚡ Улучшить»: автоподбор самого быстрого DNS + анти-сон модема (Keep-Alive)
- «Глубокая проверка» с выбором действий
- 3 режима: Обычный / Игра / USB-модем (для ПК Windows 10/11)
- Живой радар сигнала со звуком и вибрацией
- DNS-бенчмарк реальных запросов + блокировка рекламы и трекеров (локальный VPN)
- Пинг-тестер игр (Standoff 2, PUBG, CS2, Dota 2, Valorant…) + свой IP/домен
- Спидтест + Bufferbloat
- Тест «Потянет ли…»: честный вердикт по 4K-видео, видеозвонку, играм, мессенджерам и файлам (идея из nPerf)
- Живой график трафика топ-3 приложений + алерт «новое приложение начало качать» (идея из GlassWire)
- Лог DNS-запросов: какие домены дёргают приложения + локальная блокировка трекеров (идея из RethinkDNS)
- Подсказка «Wi-Fi медленнее 4G» с автопереключением (идея failover из Speedify)
- Онбординг при первом запуске: разрешения + выбор режима (1 экран)
- Быстрая плитка в шторке Android (вкл/выкл оптимизации в 1 тап)
- Виджет на рабочий стол: скорость и пинг
- Экспорт сессии в PNG-карточку для шаринга
- Монитор трафика приложений: кто ест интернет, блок сети каждому, Белый список
- Тонкая строка пинга поверх игр, тихая шторка, плитка, виджет
- Сессии: сохранение, графики, сравнение 2 сессий, экспорт
- Профили операторов РФ/СНГ (МТС, МегаФон/Yota, Билайн, t2, СНГ)
- 3 темы: Aurora / Кибер-неон / Светлая
- Shizuku/Root: супер-фичи (переподброс сети, стоп приложений в 1 тап)

## Как получить готовый APK (бесплатно, без установки Android Studio)

1. Зарегистрируйся на https://github.com (бесплатно).
2. Создай репозиторий: **New repository** → имя `doxaiz` → **Create**.
3. Залей файлы проекта:
   - Открой репозиторий → **Add file → Upload files** → перетащи ВСЕ файлы
     из папки `doxaiz-android` (включая скрытую папку `.github`!) → **Commit changes**.
   - Если папка `.github` не загружается через веб — загрузи её отдельно:
     Add file → Create new file → введи путь `.github/workflows/build-apk.yml` → вставь содержимое.
4. Открой вкладку **Actions** → запустится сборка (3–5 минут).
5. Когда сборка станет зелёной — скачай артефакт **NetOptimizer-by-Doxaiz**
   (внизу страницы Actions → Artifacts) → распакuj → получишь `app-debug.apk`.
6. Перенеси APK на телефон (Infinix Hot 50), установи (разреши «установку из неизвестных источников»).
7. При первом запуске выдай разрешения: геолокация (для сигнала), телефон, уведомления.

## Сборка локально (если есть Android Studio)
Открой папку проекта в Android Studio → Run ▶ на устройстве.
Или из командной строки: `./gradlew assembleDebug` (нужен JDK 17 + Android SDK).

- Интернет для сборки не нужен на телефоне — только для скачивания APK

## Журнал проверок и исправлений (v1.1.1)

Глобальный аудит: баги, безопасность, оптимизация.

### Исправленные баги
- VPN-сервис теперь перестраивает интерфейс при каждом старте — смена DNS и списка блокировок применяется мгновенно
- Запрос VPN-разрешения через документированный `VpnService.prepare()` (раньше был нестандартный способ)
- Защита от краша, если VPN не разрешён (establish() == null)
- Онбординг: настоящие запросы разрешений (уведомления, доступ к статистике) вместо тумблеров-заглушек
- Настройки: при включении оверлея без разрешения — переход в системные настройки
- Сессии: реальные данные сигнала и пинга вместо демонстрационных заглушек

### Безопасность
- Foreground-уведомления сервисов для Android 14+ (тип specialUse + property)
- FileProvider только на cacheDir, без лишних доступов
- DNS-лог и сессии хранятся только на устройстве, отправки данных нет

### Оптимизация
- DNS-бенчмарк: 6 серверов замеряются параллельно (было последовательно — до 45 сек)
- Цикл пинга на Главной: каждые 5 сек с автопилотом, каждые 15 сек без (экономия батареи)
- Оверлей и виджет получают живые данные из приложения
- Защита от роста памяти в мониторе трафика
